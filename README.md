# Workshop IA na produção

Material do workshop "IA na produção: do prompt à decisão" (Engenharia de Produção).

- `/` → guia de estudo, o link para os alunos (computador ou celular)
- `/apresentacao` → apresentação do instrutor. O QR code do slide 4 aponta automaticamente para o domínio onde o site estiver publicado.

## Rodar localmente

```
npm install
npm start
```

Publicado na Railway como site estático servido com `serve`.
